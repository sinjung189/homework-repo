## SaaS 서비스 비교 분석
---

## 자주 사용하는 서비스 목록
- 크롬 
- 네이버 
- 네이버웹툰, 
- 넷플릭스 
- 유튜브 
----

## 판별 기준  
- 웹 브라우저로 접속
- 설치 없이 바로 사용가능?
- 구독료 ( 요즘제 ) 이용해하나?
- 자동 업뎃이 되나?

----

<br>

## 크롬 
  - 웹으로 사용 가능
  - 업뎃 자동
  - 무료로 사용 가능

## 네이버
   - 웹 브라우저 접속
   - 계정 로그인 후 사용 가능
   - 자동 업뎃
     
## 네이버 웹툰
  - 웹에서 바로 사용가능
  - 계정 ( 로그인 이용 가능 )
  - 일부 유료(쿠기) 존재
  - 콘텐츠,기능 자동 업뎃 

## 넷플릭스
  - 설치 없이도 웹에서 바로 사용가능
  - 구독료 ( 요금제 ) 존재
  - 자동업뎃 ( 스트리밍 포함 ) 

## 유트브
  - 웹 가능
  - 무료도 가능하고 프리미엄 구독 ( 요금제 ) 존재
  - 기능 자동업뎃 ( 광고 포함 ) 

## SaaS 아닌 경우는 
= 웹에서 바로 쓰고 돈 구독으로 내고 , 업뎃 신경 안써도 되면 -> SaaS 라고 보면됨
